# 도로명변환기

카메라로 한국 주소를 읽고 지번과 도로명을 서로 바꿔주는 네이티브 Android 앱입니다.

## 구현된 기능

- CameraX 실시간 카메라 미리보기
- 네모칸 내부 픽셀만 잘라 OCR에 전달하며, 테두리·둥근 모서리 바깥과 경계에서 잘린 글줄 제외
- ML Kit 한국어 모델을 이용한 기기 내 OCR
- OCR 결과에서 지번 또는 도로명 주소를 구조에 따라 판별하고 상세 동·층·호는 검색에서 제외
- 전국 행정명·법정리·도로명 관계 사전으로 OCR 오자를 교정하고 설정 지역을 우선 적용
- 같은 주소 후보를 안정적으로 유지하고 완성된 후보로 보완
- 줄바꿈으로 끊긴 도로명·건물명·호수를 같은 OCR 블록 안에서 제한적으로 복원
- 인식 결과 직접 수정 및 재검색
- 하단에서 바로 선택할 수 있는 최대 3개 인식 후보와 수동/연속 스캔 모드
- 하나의 완성 원문 주소는 사전·점수·연속 인식 대기 없이 바로 검색하며, API의 정확 일치 결과만 변환 완료로 표시
- 같은 위치에서 사용하는 수동 모드의 다시 스캔 / 연속 모드의 일시정지·재개 버튼
- 변환된 주소를 네이버지도 또는 카카오맵에서 바로 검색하고 선택한 지도 앱 기억
- VWorld 우선, 네이버 지도·카카오맵 대체 검색을 이용한 전국 지번↔도로명 양방향 변환
- 네이버·카카오 미등록 시 VWorld 자동 사용, 민간 API 등록 시 VWorld 사용 여부 선택
- 기본 VWorld API 키를 노출하지 않는 독립 설정 화면과 개인 키 교체 기능
- 네이버 지도와 카카오맵 개인 API 정보 입력·삭제
- API 설정 카드를 서비스 이름, API 설명, 설정 상태의 3단 구조로 표시
- 정보 영역에 앱 이름과 현재 버전 표시
- GitHub Release를 하루 한 번 자동 확인하고 설정 화면에서 수동 업데이트 확인
- 고정 좌표 대신 제약 기반 반응형 메인 화면 사용
- 작은 화면·가로 화면·폴드형 넓은 화면별 크기 조정 및 콘텐츠 최대 너비 제한
- 큰 글자에서도 주소 입력과 결과가 잘리지 않도록 2줄 입력 및 결과 패널 스크롤 지원
- 상단 카메라 영역은 고정하고, 하단 정보만 스크롤하며 설정·주요 조작 버튼은 항상 표시
- 기본 지역은 도·시 전체 또는 시·군·구까지 설정 가능. 각 선택 단계의 ‘여기까지 저장’으로 바로 저장하며 ‘세부 선택’을 눌렀을 때만 다음 단계로 이동
- 집·우편·위치·검색을 결합한 전용 런처 아이콘
- 플래시, 다시 스캔, 카메라 권한 처리

## APK 설치

`RoadNameConverter-v2.0.0.apk`를 Android 6.0(API 23) 이상의 카메라가 있는 기기에 복사해 설치합니다. 디버그 서명된 테스트용 APK이므로 Play 스토어 배포용 서명 파일은 별도로 만들어야 합니다.

### v1.12.0 정확 검증·정지 영역 선택

- ML Kit 한국어 내장 OCR 16.0.1 / CameraX 1.4.2 유지. 새 엔진·재학습·모델 다운로드 없음.
- API 결과의 지역·동/리·산·본번·부번을 비교하며, 5→5-1 같은 유사 결과나 여러 지역의 동일 지번을 자동 확정하지 않습니다. 유사 결과는 수동 선택만 가능합니다.
- 같은 CameraX ViewPort의 실제 cropRect, 회전, fill-center 확대·잘림으로 원본 ROI를 계산합니다. OCR에는 잘라낸 픽셀만 전달합니다.
- 글자 크기와 무관하게 위치·주소 구조로 같은 프레임의 줄을 묶습니다. 과거 프레임 문자열을 현재 주소에 합치지 않습니다.
- 기본주소와 동·층·호수/명시적 건물 문맥을 분리합니다. 상세주소가 달라지면 선택 상태는 갱신하되 기본주소 API 요청·결과 캐시는 재사용합니다.
- 설정 → ‘화면 정지 및 영역 선택’(기본 OFF): 고해상도 정지 촬영, 상자 이동·모서리 조절·두 손가락 확대, 최초 인식, 수동 재인식, 촬영 재개. 사진은 메모리에만 유지합니다.
- 설정 → ‘개발자 모드’(기본 OFF): OCR 원문, 실제 잘린 처리 이미지·좌표, 추출 주소, 검색 결과, 실패 단계를 화면에 표시합니다. 자동 저장·진단 데이터 전송은 없습니다.
- 입력 편집 중 OCR 덮어쓰기와 이전 요청 결과를 차단합니다. 키보드가 열린 상태의 뒤로가기는 키보드를 먼저 닫고, 그다음 정지 촬영을 종료합니다.

검증 내역과 기기 미검증 범위는 `PRECISE_SCAN_PATCH_NOTES.md`에 기록했습니다.

### v1.11.4 오프라인 인식 흐름

- 한국어 OCR 모델과 주소 사전은 APK에 들어 있습니다. 첫 실행 시 다운로드하지 않아도 인식·명칭 교정·지역 선택·후보 선택은 가능합니다.
- 인터넷 연결이 없으면 새 주소 변환 API를 호출하거나 기다리지 않고, 하단 후보와 선택한 주소를 유지하며 ‘주소 인식 완료 · 변환 대기’를 표시합니다.
- 연결 복구 후 ‘주소 변환’으로 재시도할 수 있습니다. 수동 모드의 ‘다시 스캔’과 연속 스캔 동작은 유지합니다.
- 요청 중 연결이 끊어지거나 다른 주소를 선택하면 이전 응답을 무시합니다. 오프라인·통신 실패는 변환 성공이나 주소 없음으로 저장하지 않습니다.
- 사전 업데이트는 인터넷 연결 시에만 확인합니다. 업데이트 실패가 내장 사전 사용을 막지 않습니다.
- 명칭 유사도 교정에서 도로명·지명 내부 숫자의 변경·추가·삭제를 차단합니다.
- 내장 사전에는 건물별 지번↔도로명 대응 정보가 없습니다. 실제 존재 확인과 새로운 주소 변환은 인터넷이 필요합니다. 같은 실행 중 이미 확인한 변환 결과의 메모리 캐시는 재사용할 수 있습니다.

네트워크 제한은 원격 요청에만 적용합니다. [ML Kit 공식 안내](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)의 bundled 한국어 모델을 사용하며, 실제 APK에 한국어 모델 파일과 사전이 포함되는지 회귀 테스트로 확인합니다.

### v1.11.3 사전 로딩 수정

- APK 빌드 중 압축이 풀려 `address_dictionary.tsv`로 저장되는 내장 사전과 `.tsv.gz` 압축 사전을 모두 읽습니다.
- 사전 업데이트 비교는 압축 파일 자체가 아닌 압축 해제된 내용으로 수행합니다.
- 지역 설정은 사전 로딩 실패 후에도 다시 눌러 재시도할 수 있으며, 로딩 중 누르면 완료 후 선택창을 엽니다.
- 회귀 테스트에서 조립된 실제 APK 안의 사전을 열어 지역 목록·주소 후보와 업데이트 파일의 내용 일치를 확인합니다.

## 전국 주소 변환 설정

한글 OCR은 기기에서 동작합니다. 네이버·카카오 API가 하나도 등록되지 않았으면 내장된 VWorld 키를 자동으로 사용하며 끌 수 없습니다. 네이버 또는 카카오 API를 등록하면 VWorld 스위치가 활성화되고 기본값은 꺼짐입니다. VWorld를 직접 켰을 때의 검색 순서는 VWorld → 네이버 → 카카오입니다. 앱 하단의 **설정**에서 VWorld 개인 키 또는 네이버 지도·카카오맵 API 정보를 입력할 수 있습니다.

개발 시에는 프로젝트의 `local.properties`에 아래 값을 넣어 기본 키를 주입할 수도 있습니다.

```properties
sdk.dir=C\:\\Android\\Sdk
VWORLD_API_KEY=발급받은_VWorld_API_키
```

> 공개 배포 앱에서는 API 키가 앱에서 추출될 수 있으므로, 주소 검색 요청을 자체 서버가 대신 처리하는 구성이 안전합니다. 현재 구현은 기능 검증용 프로토타입입니다.

## 소스 빌드

Android Studio에서 프로젝트를 연 뒤 Android SDK 35를 설치하고 실행하거나 다음 명령을 사용합니다.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

생성 파일: `app/build/outputs/apk/debug/app-debug.apk`

## 내장 주소 사전

`tools/update_address_dictionary.ps1`은 주소정보누리집의 현존 도로명 관계와 행정표준코드관리시스템의 현존 법정동·리 자료를 받아 `app/src/main/assets/address_dictionary.tsv.gz`를 만듭니다. 건물번호, 상세주소, 좌표는 넣지 않습니다.

```powershell
.\tools\update_address_dictionary.ps1
```

생성한 파일을 GitHub의 최신 공개 Release에 `address_dictionary-날짜.tsv.gz`라는 이름으로 첨부하면 APK를 다시 설치하지 않고 사전만 교체할 수 있습니다. 최초 실행 시 백그라운드에서 자동 확인하며 **설정 → 주소 사전 업데이트**에서도 확인할 수 있습니다. 다운로드 중이거나 Release에 사전 파일이 없어도 내장본으로 바로 인식합니다. 파일 크기·전체 행·버전을 검증하고 동일 파일 및 구버전 교체를 건너뛴 뒤 앱 내부 저장소에 원자적으로 설치합니다. 실패하면 기존 사전을 유지하고 다음 앱 실행 때 다시 확인합니다.

## GitHub 업데이트

앱은 `https://github.com/greatrima/roadnameconverter`의 최신 공개 Release를 확인합니다. Release 태그는 `v1.8.0`처럼 버전 번호로 만들고 APK 파일을 Release asset으로 첨부합니다. 이후 업데이트는 앱의 `versionCode`와 `versionName`을 올리고 더 높은 버전 태그로 새 Release를 게시합니다.

- 앱 실행 자동 확인: 최근 성공 확인으로부터 24시간마다
- 수동 확인: 설정 → 업데이트 → 업데이트 확인
- APK asset이 있으면 다운로드 주소를 열고, 없으면 Release 페이지를 엽니다.

## 권한 및 데이터 처리

- 카메라 권한: 화면의 주소 촬영 및 실시간 인식에 사용
- 인터넷 권한: 설정된 VWorld·네이버 지도·카카오맵 주소 검색 API 호출에 사용
- 촬영 영상: 서버로 업로드하거나 파일로 저장하지 않음
- 인식 문자열: 온라인 주소 변환 시 사용 가능한 주소 검색 API로 전송
